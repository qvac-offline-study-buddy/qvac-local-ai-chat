# QVAC Local AI Chat

A simple local AI chat application built with the QVAC SDK. It loads a local AI model and generates responses using QVAC's `loadModel()` and `completion()` APIs.

## Features

- Local AI chat
- Model loading with QVAC
- AI text completion
- Simple chat interface

## Requirements

- Node.js
- npm
- QVAC SDK 0.20.0
